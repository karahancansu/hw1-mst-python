🌳 Minimum Spanning Tree (MST) in Python

A clean and simple Python project that solves the **Minimum Spanning Tree (MST)** problem for an **undirected weighted graph** using **Prim’s Algorithm**.

The program:

- reads the graph from `udg.dat`
- computes the MST
- prints the **total minimum cost**
- writes the resulting MST matrix into `mst.dat`

---
 ✨ What This Project Does

This project takes a graph represented as an **adjacency matrix** and finds a tree that:

- connects **all vertices**
- uses the **minimum possible total weight**
- contains **no cycles**

In short, it finds the cheapest way to connect all nodes in the graph.
